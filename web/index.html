Research and teaching demo, not a medical device. A flagged X-ray needs a lab test; a clear one does not rule TB out. Not for children under 15.

The problem

Pakistan has one of the world's largest TB burdens, and many cases are never diagnosed. Chest X-rays are cheap and available almost everywhere; people trained to read them for TB are not.

highest TB burden in the world: 6.3% of all cases
2021
WHO first recommended computer-aided detection (CAD) software in place of a human reader for TB screening, age 15+

because the hard part is telling TB from other lung disease, not from a healthy chest
What LungLens does
  • X-ray in → probabilities for healthy, sick-but-not-TB and TB, plus a heatmap.
  • Screening rule: refer for a lab test if TB probability ≥ 0.7%. The threshold is fixed on validation data at 95% specificity; on the test set that catches 100.0% of TB cases, above WHO's 90% minimum for a triage test.
  • Runs entirely in the browser (ONNX Runtime Web): works offline once loaded, costs nothing to serve, uploads nothing.
Why it is not a toy
  • Most student TB projects use a dataset where TB and normal X-rays come from different hospitals, so a model can learn "which hospital" instead of "which disease".
  • TBX11K's classes share sources, and its "sick but not TB" class forces the model to separate TB from pneumonia-like disease.
  • We test where the model looks against boxes doctors drew around TB: the pointing game.

Handling the data
  • Grayscale, resized to 384×384 (TB lesions are small; 224 px loses them).
  • TB is 9% of the training set: the loss weights TB about 5× more.
  • Augmentation on the GPU: small rotations, shifts, zooms, exposure/contrast/gamma changes, noise, blur.
  • No horizontal flips: a flipped X-ray puts the heart on the wrong side, which never happens in real life.

Models: one question at a time

Three models, trained with identical data, augmentation, loss and schedule. The two DenseNets differ only in their starting weights, which isolates one question: does it help to start from a network that has already seen chest X-rays?

ModelStartWhy it is here
CNN from scratchrandom weightsBaseline: 5 conv blocks (2.4M params). What deep learning does with no prior knowledge.
DenseNet-121ImageNet (photos of objects)Standard transfer learning; same architecture as Stanford's CheXNet.
DenseNet-121chest X-rays from 7 public datasets: NIH, CheXpert, MIMIC-CXR, PadChest and more (TorchXRayVision)Domain-specific pretraining: has it learned what lungs look like?
Training
  • AdamW, weight decay 0.05, cosine schedule with warm-up; 20 epochs (DenseNets), 40 (scratch).
  • Batch 32, mixed precision, one NVIDIA L4 GPU on Google Colab.
  • Best epoch chosen by validation balanced accuracy; test set never used for any choice.
Heatmaps without gradients
  • Every model ends in global average pooling + one linear layer, so the class activation map (CAM, Zhou et al. 2016) comes out of the same forward pass.
  • That is why the browser can draw the heatmap: the ONNX model returns probabilities and maps.

Results on 1,800 test X-rays

The deployed model is DenseNet-121 (ImageNet start), chosen on validation data. On the 1,800 untouched test X-rays it is 99.2% accurate across the three classes and separates TB from everything else with an AUC of 0.9996. At the screening threshold it catches 100.0% of TB cases (200 of 200). Starting from chest X-rays instead of ImageNet changed TB AUC by -0.0031 and balanced accuracy by -1.4 points.

Honest limits
  • TBX11K comes from Chinese hospitals; the model has not been tested on X-rays from Pakistani hospitals.
  • Trained on adults; WHO's CAD recommendation is for people aged 15 and over.
  • The screening threshold was set on validation X-rays from the same hospitals; a new population needs its own threshold (our first rule, set on only 60 validation TB X-rays, did not transfer to the test set).
  • A heatmap shows where the evidence is, not a lesion outline; a high pointing-game score is not a diagnosis.
  • The official TBX11K test labels are hidden; our test set is its labelled validation set, so numbers are not directly comparable to the leaderboard.
